# 🖥️ Sistemas Paralelos 2026 - Cronograma de Actividades

Este repositorio contiene la planificación detallada de la asignatura **Sistemas Paralelos** para el ciclo lectivo 2026, abarcando desde los conceptos teóricos fundamentales hasta la implementación práctica en clusters.

---

## 📅 Calendario del Semestre

*   **18/03** | 💻 **Laboratorio TP1**: Punteros y gestión de memoria dinámica en C.

## 🛠️ Tecnologías y Conceptos Clave
*   **Lenguajes:** C (Punteros, `malloc`, `free`).
*   **Modelos:** Memoria compartida (OpenMP) y Memoria distribuida (MPI).
*   **Hardware:** Clusters, Supercomputadoras y Aceleradoras (GPUs).
*   **Métricas:** Speedup, Eficiencia y Escalabilidad.
