TP1: Punteros y Gestión de Memoria en C Completo

Fundamentos de punteros y gestión de memoria dinámica en C. El objetivo es comprender la asignación de memoria dinámica y el direccionamiento por punteros para implementar programas utilizando estructuras de datos de gran tamaño.

Temas Cubiertos

  • Punteros básicos y operadores de dirección/indirección
  • Punteros y arreglos (notación de punteros)
  • Punteros a punteros (indirección múltiple)
  • Organización de memoria (Stack, Heap, BSS, Data, Text)
  • Asignación dinámica de memoria (malloc/free)

TP2: Uso de un Cluster Completo

Uso práctico del cluster III-LIDI (IP: 163.10.34.49) utilizando el gestor de carga de trabajo SLURM. Se enfoca en transferencia de archivos SSH/SCP, envío de trabajos, gestión de nodos e inspección de recursos.

Temas Cubiertos

  • Acceso al cluster via SSH
  • Gestión de archivos con SCP
  • Inspección de recursos con sinfo
  • Envío de trabajos con sbatch
  • Estados de trabajos y cancelación
  • Detalle de recursos de nodos

TP3: Optimización de Alto Rendimiento Completo

Técnicas de optimización de código de alto rendimiento. Este es el TP más extenso, organizado en 10 partes más un ejercicio adicional. Cada ejercicio explora una técnica de optimización manual, midiendo su impacto en tiempo de ejecución y uso de memoria.

Resultados Medidos

Ejercicio Técnica Mejora
2.2 float → int ~37% más rápido
3 int → char (bool) 75% menos memoria
4 Código inline ~85% más rápido
5 Loop unroll + ILP ~76% más rápido
6 Subexpresión común ~30% más rápido
7 Evitar ramas ~12% más rápido
8 Localidad de caché ~93% más rápido (14x)
9 SIMD (SSE 4.2) ~62% más rápido (2.6x)
10 SIMD + Branchless ~78% más rápido (4.5x)
Adicional SIMD + Branchless ~21% más rápido (1.26x)

TP4: Evaluación de Rendimiento En Progreso

Evaluación de rendimiento de aplicaciones paralelas usando OpenMP. Se enfoca en instrumentación para medición de tiempo, escalabilidad fuerte y escalabilidad débil.

Temas Cubiertos

  • Programa Julia Set con OpenMP
  • Escalabilidad fuerte (tamaño de problema fijo)
  • Escalabilidad débil (problema crece con cores)
  • Instrumentación de programas para medición de tiempos
  • Cálculo de aceleración (speedup)
