📚 Descripción del TP

Fundamentos de punteros y gestión de memoria dinámica en C. El objetivo es comprender la asignación de memoria dinámica y el direccionamiento por punteros para implementar programas utilizando estructuras de datos de gran tamaño.

1️⃣ Punteros

Ejercicio 1.1 - Introducción a Punteros

Archivo: archivo.c

int x = 10;      // Variable entera con valor 10
int *p;          // Declaración de puntero a entero
p = &x;          // p almacena la dirección de memoria de x
Explicación:
  • &x → Obtiene la dirección de memoria donde está almacenada x
  • p = &x → El puntero p ahora contiene esa dirección
  • *p → Desreferencia el puntero, accediendo al valor almacenado en esa dirección (10)

Resultado esperado:

Dirección de x: 0x7fff... (ejemplo)
Dirección almacenada en p: 0x7fff... (misma dirección)
Valor de *p: 10
⚠️ Nota: El código tiene un error en el último printf - usa %p para imprimir *p cuando debería usar %d.

Ejercicio 1.2 - Asignación entre Punteros

Archivo: ej1-2.c

Análisis paso a paso:

a = 10;           // a = 10
b = 20;           // b = 20
x = &a;           // x apunta a a
y = &b;           // y apunta a b
x = y;            // x ahora apunta a b (mismo dirección que y)
*x = 5;           // modifica el valor apuntado por x → b = 5

Resultado final:

Variable Valor
a 10
b 5
Conclusión: Al hacer x = y, ambos punteros apuntan a b. Por lo tanto, *x = 5 modifica b, no a.

2️⃣ Punteros y Arreglos

Ejercicio 2.1 - Notación de Punteros en Arreglos

Archivo: ej2-1.c

float a[5];
*(a+4) = 10.0;           // notación de punteros para acceder al 5º elemento
printf("El quinto elemento es %f\n", a[4]);    // notación de arreglos para imprimir
Explicación:
  • a es un puntero al primer elemento del arreglo
  • *(a+4) accede al elemento en la posición 4 (quinto elemento, índice base 0)
  • Equivale a a[4]

Ejercicio 2.2 - Matrices y Almacenamiento en Memoria

Archivo: ej2-2.c

Conclusión: Las matrices en C se almacenan en orden row-major (por filas). Esto significa que los elementos de una fila se almacenan contiguos en memoria, y luego sigue la siguiente fila.

Ejemplo de salida:

a[0][0] = 0x7fff...00
a[0][1] = 0x7fff...04
a[0][2] = 0x7fff...08
a[0][3] = 0x7fff...0C
a[1][0] = 0x7fff...10    ← continúa después de la fila 0
a[1][1] = 0x7fff...14
...

Cada int ocupa 4 bytes, por eso las direcciones incrementan de 4 en 4.

3️⃣ Punteros a Punteros

Ejercicio 3.1 - Indirección Múltiple

Archivo: ej3-1.c

Análisis paso a paso:

num = 123;          // num = 123
p1 = #          // p1 apunta a num
p2 = &p1;           // p2 apunta a p1 (puntero a puntero)

*p1 = num - 23;     // num = 123 - 23 = 100
**p2 = *p1 * 2;     // **p2 accede a num → num = 100 * 2 = 200
Explicación:
  • *p1 accede directamente a num
  • **p2 es equivalente a *p1, que es equivalente a num
  • Ambas operaciones modifican la misma variable num

Resultado final: Valor de num = 200

4️⃣ Organización de la Memoria

(Ejercicio teórico - no tiene código asociado)

Segmentos de memoria:

🥞 Stack

Variables locales, parámetros de funciones, direcciones de retorno. LIFO. Tamaño fijo (~8MB).

🏔️ Heap

Memoria dinámica (malloc/free). El programador gestiona la liberación.

🌑 BSS

Variables globales/estáticas no inicializadas (inicializadas en 0 por defecto).

🌕 Data

Variables globales/estáticas inicializadas con valor ≠ 0.

📜 Text

Código del programa (instrucciones de máquina). Solo lectura.

5️⃣ Asignación Dinámica de Memoria

Ejercicio 5.1 - malloc Básico

Archivo: ej5-1.c

int *p;
p = (int *) malloc(sizeof(int));
*p = 50;
Explicación:
  1. int *p; → declara un puntero a entero
  2. malloc(sizeof(int)) → reserva 4 bytes en el Heap
  3. (int *) → castea el void* retornado por malloc a int*
  4. *p = 50; → almacena el valor 50 en la memoria reservada
Importante: El cast es necesario porque malloc retorna void*. El tipo de casteo determina cómo se interpretará la memoria al recorrerla (de 4 en 4 bytes para int, de 1 en 1 para char, etc.).

Ejercicio 5.2 - Arreglo Dinámico

Archivo: ej5-2.c

⚠️ El código original tiene un error de compilación: 
int p[5];           // ← p declarado como arreglo
int *p = malloc(...); // ← ERROR: redeclaración de p

Corrección sugerida:

int *p = (int *) malloc(sizeof(int) * 5);  // reserva espacio para 5 enteros
p[0] = 1; p[1] = 2; p[2] = 3; p[3] = 4; p[4] = 5;

Ejercicio 5.3 - Matriz Dinámica con Filas Unidas

Archivo: ej5-3.c

Implementación con filas unidas (un único bloque contiguo):

int X = 3, Y = 4;

// Reservar un único bloque contiguo para todos los elementos
int *a = (int*) malloc(X * Y * sizeof(int));

// Reservar arreglo de punteros para las filas
int **x = (int**) malloc(X * sizeof(int*));

// Hacer que cada fila apunte a la posición correspondiente del bloque
for(int i = 0; i < X; i++){
    *(x+i) = a + i*Y;
}
Ventajas de filas unidas:
  • ✅ Mejor localidad espacial (acceso más rápido por caché)
  • ✅ Una sola llamada a free() para los datos
  • ✅ Memoria contigua (mejor para operaciones vectoriales)

Ejercicio 5.3.c) Memoria Máxima Disponible

i) Comando free:

$ free -h

Busca la columna available en la fila Mem. Ese es el espacio máximo sin usar swap.

ii) Cálculo para matriz de double:

Tamaño de double = 8 bytes

Si available = 7.5 GB ≈ 8,053,063,680 bytes

Número máximo de elementos = 8,053,063,680 / 8 ≈ 1,006,632,960 elementos

Esto equivale aproximadamente a una matriz de 31,700 × 31,700 elementos.
